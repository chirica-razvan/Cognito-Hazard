# Cognito Hazard

Created by Chirica Răzvan and Sandu Daniel

Cognito Hazard aims to support the study titled „The Capacity of XR Media to Affect Cognitive Abilities”. The objective is to investigate whether and to what extent immersive XR environments impair or alter human cognitive performance compared to traditional 2D display platforms. 

To collect the empirical data required for this research, we designed the Cognito Hazard cross-platform application (VR and Windows Desktop pair), which assesses executive functions through an interactive dual-task paradigm. The protocol consists of two distinct stages:
Baseline Phase: The participant performs a cognitive task in a neutral, non-threatening environment to establish baseline control metrics (baseline error rate, response latency, and resting heart rate).

Stress/Experimental Phase: The participant is exposed to an acute threat scenario with an active deadline constraint. While continuing the same primary cognitive task, a looming spatial threat approaches from behind. The user can freely turn to inspect the threat at the cost of task-solving time (gaze/attention switching cost). Throughout both phases, the system continuously logs the error rate, task-dwell time versus threat-monitoring time, and heart rate telemetry. Using a between-subjects design, half of the cohort completes the experiment in immersive Virtual Reality, while the other half completes the exact equivalent setup on a desktop computer. The aggregated datasets will be compared to evaluate the differential impact of environmental duress on cognition across the two media.

While conventional cognitive assessment tools focus primarily on measuring static mental capabilities in neutral settings, Cognito Hazard directly investigates how dynamic, high-stress XR environments modulate and degrade cognitive resilience in real time.
